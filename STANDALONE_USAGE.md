# Использование модуля проверки ссылок как отдельного компонента

## 🎯 Да, можно использовать только функцию проверки ссылок!

Модуль проверки ссылок **полностью независим** и использует **только ваш AI ключ** для работы.

## ✅ Что использует модуль

### API Ключи (ваши, уже настроены):
- **OpenRouter**: `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`
- **Google AI** (fallback): `AIzaSyBFvQQz_PQdg4jTpwefpfPuiAyV7OMT9aw`

### Зависимости:
- ✅ Laravel Framework (базовый)
- ✅ Python 3.8+ с библиотеками: requests, beautifulsoup4, google-genai, dnspython
- ✅ OpenRouter API (через ваш ключ)
- ✅ Google AI API (через ваш ключ, как fallback)

### Что НЕ используется:
- ❌ База данных (не требуется)
- ❌ Другие сервисы проекта
- ❌ Внешние API кроме OpenRouter/Google
- ❌ Дополнительные порты или сервисы

## 🔄 Как это работает

```
Пользователь → /check/link (POST)
    ↓
CheckController::checkLink()
    ↓
PhishGuardService::fullAudit()
    ↓
Python скрипт (phishguard_audit.py)
    ↓
OpenRouter AI API (ваш ключ) → Результат
    или
Google AI API (ваш ключ, fallback) → Результат
```

## 🚀 Использование вашего друга

### Вариант 1: Использовать весь проект

Ваш друг может:
1. Клонировать проект
2. Установить зависимости
3. Использовать **только** `/check/link` страницу
4. Игнорировать все остальные функции

### Вариант 2: Интегрировать только модуль

Ваш друг может скопировать только файлы проверки ссылок в свой проект (см. `INTEGRATION_GUIDE.md`).

## 🔑 Использование ваших ключей

**Да, ваш друг может использовать ваши ключи!**

Ключи уже в `.env` файле:
- OpenRouter ключ работает с бесплатной моделью

Если ваш друг хочет использовать свои ключи, он может:
