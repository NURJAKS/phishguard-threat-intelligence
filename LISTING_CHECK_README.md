# Проверка объявлений - Интеграция scikit-learn, Scrapy и Gemini AI

## Обзор

Система проверки объявлений использует три основных компонента:

1. **Scrapy** - парсинг объявлений с веб-сайтов
2. **scikit-learn** - ML анализ для определения риска мошенничества
3. **Gemini AI** - интерпретация результатов (ТОЛЬКО для объяснения)

## Архитектура

```
Пользователь вводит URL/текст
    ↓
Scrapy парсит данные (если URL)
    ↓
scikit-learn анализирует признаки
    ↓
Gemini AI интерпретирует результаты
    ↓
Отображение результата
```

## Использование

### Через веб-интерфейс

1. Перейдите на страницу "Проверка объявления"
2. Введите URL объявления (например, `https://krisha.kz/...`) ИЛИ текст объявления
3. Нажмите "Анализировать"
4. Система покажет результаты проверки

### Через API (программно)

```php
use App\Services\ListingCheckService;

$listingCheckService = app(ListingCheckService::class);

// Проверка по URL
$check = $listingCheckService->checkListing(
    url: 'https://krisha.kz/a/show/123456',
    text: null
);

// Проверка по тексту
$check = $listingCheckService->checkListing(
    url: null,
    text: 'Продаю квартиру, срочно, недорого...'
);
```

## Что анализируется

### Признаки для ML анализа:

- Длина текста объявления
- Подозрительные ключевые слова (срочно, быстро, предоплата и т.д.)
- Анализ цены (слишком низкая/высокая)
- Наличие контактной информации
- Наличие фотографий
- Качество описания
- Ключевые слова срочности

### Результаты интерпретации (Gemini AI):

- **Summary** - краткое резюме проверки
- **Interpretation** - детальное объяснение
- **Risk Classification** - классификация риска (Low/Medium/High)
- **Key Findings** - ключевые находки
- **Recommendations** - рекомендации

## Важно

⚠️ **Gemini AI используется ТОЛЬКО для интерпретации**, не для:
- Поиска данных в интернете
- Определения фактов
- Геолокации
- Поиска в базах данных

✅ **Gemini AI используется для**:
- Объяснения результатов ML анализа
- Классификации уровня риска
- Генерации summary
- Формирования рекомендаций

## Структура файлов

- `app/Services/ListingCheckService.php` - основной сервис проверки
- `app/Services/ScrapyService.php` - парсинг объявлений
- `app/Services/MLAnalysisService.php` - ML анализ
- `app/Services/GeminiAIService.php` - интерпретация результатов
- `app/Http/Controllers/CheckController.php` - контроллер
- `resources/views/check/listing.blade.php` - форма проверки

## Модель scikit-learn

При первом использовании система автоматически создаст базовую модель RandomForest.
Для продакшена рекомендуется обучить модель на реальных данных мошеннических объявлений.

Модель сохраняется в: `ml_scripts/fraud_detection_model.pkl`
